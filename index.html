おすすめレシピ

ふわふわ卵のかんたん親子丼

調理時間：約15分 ／ 1人分

材料

  • 鶏もも肉 … 100g
  • 玉ねぎ … 1/4個
  • 卵 … 2個
  • ごはん … 丼1杯分
  • 水 … 大さじ4
  • しょうゆ … 大さじ1
  • みりん … 大さじ1
  • 砂糖 … 小さじ1
  • 三つ葉（お好みで） … 少々

作り方

  1. 鶏肉は一口大に切り、玉ねぎは薄切りにする。
  2. 小さめのフライパンに水・しょうゆ・みりん・砂糖を入れて火にかける。
  3. 煮立ったら鶏肉と玉ねぎを入れ、中火で5分ほど煮る。
  4. 溶き卵の2/3を回し入れ、ふたをして30秒ほど加熱する。
  5. 残りの卵を加えて火を止め、ふたをして10秒ほど蒸らす。
  6. ごはんにのせ、お好みで三つ葉を添えて完成。

ポイント：卵を2回に分けて入れると、ふわとろ食感に仕上がります。
